# INVENZA V26

V26 adalah upgrade additive di atas V25. Struktur V25 tetap dipertahankan.

## Fitur V26
- Inventory Intelligence dan Health Score
- Daily Briefing dan Data Quality
- Asset Passport / Inventory 360°
- Estimasi nilai berjalan aset
- Warranty Tracker
- Maintenance Center dan timeline
- Inventory Check Mode
- Barcode/QR scanner jika browser mendukung BarcodeDetector + kamera
- Rekonsiliasi sistem vs pengecekan lapangan
- Location Heatmap
- Rack Visualizer
- Snapshot & Recovery Point
- Audit log V26
- Demo Data Generator
- Command Center V26
- Presentation Mode
- Focus Mode
- PWA offline compatibility
- Shortcut Ctrl/Cmd+Shift+K, Ctrl/Cmd+Shift+P, F2
- Label printer dengan QR payload online

## Catatan QR
Pencetakan label menggunakan layanan QR image eksternal agar tidak menambah library besar ke aplikasi. Scanner menggunakan API BarcodeDetector jika browser mendukung.
